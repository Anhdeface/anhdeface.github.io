BEHIND THE CODE

A Glimpse Into My World

The mindset, daily environment, and technical passion fueling my low-level development journey.

Background & Drive

Curiosity Deep Into the Silicon

Based in Dong Thap, Vietnam. Rather than remaining on the surface of web frameworks, I am deeply fascinated by how computers truly work underneath: CPU instruction cycles, anti-debugging defenses, Linux and NixOS internals, and memory-safe systems engineering in Rust.

Active Focus

Security & Tooling

Actively developing binary analysis utilities like rvs, anti-debug evasion libraries for Rust (fdebug), and refining modular NixOS environments.

Engineering Creed

Speed, Simplicity & Zero Waste

Prioritizing clean execution paths, minimal memory footprints, and ruthless reduction of bloated dependencies across every system I touch.

Daily Environment

Daily Driver: Declarative NixOS

Driven by deterministic reproducibility and minimalism. When taking a break from terminal sessions, I study binary exploitation, listen to electronic synth beats, and experiment with new low-level concepts.
